# BasicResetAPI
I created a Basic REST API using core Java without any framework. This project helps to understand how backend systems handle HTTP requests and responses. I used Java sockets/simple HTTP server to create endpoints and return responses for GET and POST requests.




Features
Start a simple server on localhost
Handle client requests
Create GET API
Create POST API
Send text/JSON response
Understand request-response flow



Example Endpoints
GET /hello → Returns welcome message
POST /data → Accepts and returns data



What i Learned
Backend basics
API working process
HTTP methods
Request and response handling
Routing concepts in Java


 conclusion:
Through this project, I understood the basic working of REST APIs and how servers communicate with clients using HTTP requests and responses.
